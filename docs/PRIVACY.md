# معمارية الخصوصية

المبدأ: **الخصوصية تُفرض تقنياً لا بالسياسات.** ما لا يُجمع لا يمكن تسريبه ولا طلبه.

| البيان | أين يُعالج | هل يُخزّن؟ | كيف يُفرض |
| --- | --- | --- | --- |
| نص البحث | ذاكرة عملية API | لا | لا يوجد جدول للاستعلامات. الاختبار `test_search_query_not_persisted` يبحث عن نص فريد في كل أعمدة النص بكل الجداول وفي كل مفاتيح Redis |
| عنوان IP للزائر | ذاكرة | لا | تحديد المعدل يستخدم HMAC(سر التطبيق + الساعة الحالية، IP)، والمفاتيح تنتهي خلال دقيقة. الاختبار `test_ip_not_stored_in_rate_limiter` |
| سجلات الطلبات | — | لا | uvicorn بدون access log، وnginx بـ `access_log off`، وsystemd بـ `StandardOutput=null` |
| الكوكيز للزوار | — | لا توجد | الاختبار `test_privacy_headers_and_no_cookies` |
| الصور المرفوعة | ذاكرة + عملية معزولة | لا | الاختبار `test_reverse_image_upload_not_written` يقارن ملفات القرص قبل وبعد |
| الصوت | ملف مؤقت | يُحذف فوراً | `ai.transcribe` يحذف في `finally`، والتنظيف الدوري احتياطي |
| سجل البحث | جهاز المستخدم (localStorage) | على الجهاز فقط | يمكن إيقافه ومسحه، ولا يُرسل للخادم |
| التحليلات | Redis ثم PostgreSQL | أرقام مجمّعة بالساعة | فقط: عدد البحث، الأخطاء، مجموع زمن الاستجابة، توزيع لغة الاستعلام وتبويب الفئة، عدد البحث بلا نتائج |
| بيانات المشرفين | PostgreSQL | نعم (أمنية) | IP المشرف وسجل التدقيق منفصلان تماماً عن أي بيانات بحث |

## ضمانات إضافية
- **البحث لا يظهر في الرابط:** الواجهة ترسل POST وتحفظ الحالة في `history.state`، فالرابط يبقى `/`.
- **لا اتصال بأطراف ثالثة:** CSP تمنع أي سكربت أو خط أو صورة خارجية. الخطوط من النظام، والمصغّرات من خادمنا.
- **الروابط بدون تتبع:** النتائج تفتح مباشرة مع `rel=noreferrer`، بلا إعادة توجيه عبرنا.
- **الاقتراحات من المحتوى:** الإكمال التلقائي والتصحيح الإملائي يُبنيان من نصوص الصفحات المفهرسة، لا من استعلامات المستخدمين.
- **لوحة التحكم بلا تتبع:** لا توجد أي ميزة لعرض سجل بحث فرد أو بناء ملف عن مستخدم.
- **الاحتفاظ:** سجلات الزاحف 30 يوماً، والأحداث الأمنية 90، والتدقيق 365، والتحليلات المجمّعة 400، والملفات المؤقتة 10 دقائق. كلها قابلة للضبط وتُطبّق تلقائياً كل ساعة.

## نتائج الويب العام (اختيارية)
إذا فعّل المشغّل `SUMER_BRAVE_API_KEY`، وعندما تكون نتائج فهرس سومر أقل من الحد المحدد، يرسل **خادم سومر** نص البحث فقط إلى Brave Search API ليكمّل النتائج.
- لا يُرسَل عنوان IP المستخدم ولا متصفحه ولا أي معرّف؛ المزوّد يرى عنوان الخادم فقط.
- لا يُخزَّن الاستعلام ولا النتائج، ولا تُضاف للفهرس المحلي.
- تُعرض هذه النتائج بوسم «من الويب العام» واسم المزوّد، حتى يعرف المستخدم مصدرها.
- عند عدم ضبط المفتاح (الافتراضي)، سومر يعمل بفهرسه المستقل فقط.
