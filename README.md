# سومر (Sumer) · محرك بحث عراقي مستقل

محرك بحث عراقي مستقل يحترم الخصوصية: زاحف وفهرس وترتيب وواجهة ولوحة تحكم، كلها تعمل على خوادم يملكها المشغّل. لا يستخدم Google ولا Bing ولا أي واجهة بحث أو ذكاء اصطناعي خارجية.

## ما الذي يعمل اليوم (ومختبر)

| المكوّن | الحالة |
| --- | --- |
| الزاحف: robots.txt وcrawl-delay وsitemap وcanonical والتحويلات وnoindex/nofollow والمسارات المستثناة والتكرار وكشف اللغة وPDF وإعادة الزحف بـ ETag | يعمل ومختبر |
| الاكتشاف التلقائي للويب كله (مثل Google): يتبع الروابط لأي موقع، ويرتّب الطابور حسب أهمية الصفحة (سلطة المصدر، الروابط الواردة، الأولوية العراقية، العمق)، وميزانية زحف لكل موقع تكبر مع سلطته، وعدالة بين المواقع، وحماية من فخاخ الزحف | يعمل ومختبر (يُفعّل من الزاحف ← وضع الاكتشاف) |
| الحماية من SSRF وإعادة ربط DNS (تثبيت عنوان IP المفحوص لكل اتصال) | تعمل ومختبرة |
| الفهرس المقلوب (PostgreSQL GIN) مع إصدارات وإعادة بناء بدون إعادة زحف | يعمل ومختبر |
| معالجة العربية واللهجة العراقية والعربيزي والكردية السورانية والإنكليزية | تعمل ومختبرة |
| الترتيب: صلة النص والعنوان والسلطة (PageRank للنطاقات) والجودة والحداثة واللغة والأولوية العراقية وعقوبة السبام | يعمل ومختبر |
| التصحيح الإملائي، والاقتراحات من محتوى الفهرس، والبحث ذو الصلة، ولوحة المعرفة من المصادر الرسمية | تعمل |
| بحث الصور بالنص، والبحث العكسي بصورة مرفوعة (dHash)، وكشف الصور المكررة | يعمل ومختبر |
| فحص الرابط (URL inspection) من الفهرس فقط | يعمل ومختبر |
| لوحة التحكم /admin: أقسامها الـ 11 كلها، و2FA، وصلاحيات بالخلفية، وسجل تدقيق، ونسخ احتياطي مشفّر | تعمل ومختبرة |
| البحث الصوتي (Whisper) والترجمة (NLLB) | الكود جاهز، ويحتاج تنزيل النماذج على الخادم. حتى ذلك الحين تظهر الميزة معطّلة وترجع 503، ولا تُحاكى |
| التشابه الدلالي للصور (CLIP) والتضمينات النصية | بنية الربط جاهزة، والنماذج اختيارية |

النتيجة: **82 اختباراً آلياً تنجح** (صلة النتائج، الخصوصية، امتثال الزاحف، الأمن، لوحة التحكم).

> **الاستقلال الحقيقي** يتحقق عندما يعمل الزاحف على الإنترنت من خوادمكم ويبني فهرساً حقيقياً. هذا المستودع يوفّر كل المكوّنات، لكن الفهرس يبدأ فارغاً ويكبر مع الزحف.

## البنية

```
backend/            Python 3.12+: FastAPI + الزاحف + المفهرس + الترتيب
  sumer/
    migrations/     مخطط PostgreSQL (لا يوجد جدول لاستعلامات المستخدمين)
    text.py         تطبيع، تجذيع، لهجة، عربيزي، كشف لغة، SimHash
    netguard.py     حماية SSRF وإعادة ربط DNS
    parse.py        HTML وPDF وsitemap
    crawler.py      العامل، الطابور، robots، التهذيب، مهام الصيانة
    indexer.py      الفهرسة، الجودة، السبام، التكرار
    search.py       فهم الاستعلام، الاسترجاع، الترتيب، الاقتراحات، فحص الروابط
    images.py       معالجة الصور في عملية معزولة، dHash، البحث العكسي
    ai.py           خدمات الذكاء المحلية بحالة حقيقية
    auth.py         Argon2id، جلسات، TOTP مشفّر، CSRF، صلاحيات
    api_public.py   واجهة البحث العامة
    api_admin.py    واجهة لوحة التحكم
  tests/            موقع تجريبي محلي + 75 اختباراً
frontend/           Next.js 15 + React 19 + TypeScript + Tailwind + Framer Motion + Lucide
  app/              الرئيسية والنتائج والصفحات و/admin
docker-compose.yml  postgres, redis, migrate, api, worker×2, web, nginx
deploy/nginx.conf   TLS 1.3 فقط، بدون سجلات وصول
docs/               التثبيت والنشر وواجهات API والأمن والخصوصية
```

## تشغيل سريع للتطوير

```bash
# PostgreSQL 16 وRedis 7 شغّالين محلياً
cd backend
pip install -r requirements-dev.txt
psql -c "CREATE EXTENSION IF NOT EXISTS pg_trgm" sumer
export SUMER_DATABASE_URL=postgresql://sumer:PASS@127.0.0.1:5432/sumer SUMER_COOKIE_SECURE=0
python -m sumer migrate
python -m sumer create-admin --email you@example.iq --name "اسمك"
python -m sumer seed https://www.example.gov.iq/
python -m sumer worker &          # الزاحف
python -m sumer api --port 8000 & # الواجهة البرمجية

cd ../frontend && npm ci && npm run dev   # http://localhost:3000 و /admin
```

الاختبارات: `cd backend && pytest -q` (تحتاج PostgreSQL وRedis محلياً).
