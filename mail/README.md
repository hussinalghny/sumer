# سومر بريد

تطبيق ويب عراقي يجمع حسابات البريد (Gmail وYahoo وiCloud وبريد الجامعات والمؤسسات عبر IMAP)
بمكان واحد، ويحمي المستخدم من التصيّد والانتحال والتتبّع.

## المبادئ
- **لا تخزين للرسائل.** تُجلب من خادم البريد وتُحلَّل بالذاكرة وتُعرض مباشرة.
- **جلسات بمفتاح مقسوم.** بيانات الدخول مشفّرة (AES-256-GCM) في Redis، ومفتاح فك التشفير موجود فقط في كوكي المستخدم (HttpOnly). تسريب Redis وحده لا يكشف كلمات المرور. الجلسة تنتهي بعد 12 ساعة خمول أو 7 أيام.
- **حماية من SSRF.** عناوين خوادم IMAP/SMTP اللي يكتبها المستخدم تُحلّ وتُرفض إذا كانت شبكة داخلية، ويُثبّت عنوان IP مع التحقق من شهادة TLS باسم الخادم. المنافذ المسموحة: 993 و465 و587 فقط.
- **عرض آمن.** HTML الرسائل يُعقَّم (nh3)، والصور الخارجية محجوبة افتراضياً، ويُعرض داخل iframe معزول بدون سكربتات.

## محرك الحماية (`sumermail/analyze.py`)
فشل DMARC/SPF، انتحال أسماء جهات معروفة، نطاقات شبيهة (paypa1، g00gle)، حروف مموّهة (punycode)،
اسم عرض يحمل عنوان بريد آخر، الرد لعنوان مختلف، ادعاء جهة حكومية من خارج gov.iq، ادعاء مصرف من نطاق غير عراقي،
روابط مضلِّلة (النص يعرض موقعاً والرابط يودي لغيره)، روابط IP وبرمجية ومختصرة ونطاقات عالية الخطورة،
لغة الاستعجال وطلب البيانات والجوائز بالعربي والإنكليزي، مرفقات تنفيذية أو مموّهة أو صفحات ويب أو مستندات بماكرو،
ومتتبّعات الفتح.

## التشغيل على الخادم
```
bash deploy/setup-mail.sh mail.sumeriq.tech you@email.com
```
(يحتاج سجل A للنطاق الفرعي يأشر على الخادم.)

## الاختبارات
تحتاج خادم IMAP محلي (dovecot على المنفذ 10993) وRedis:
```
cd mail/backend && pip install -r requirements-dev.txt && pytest -q
```

## حدود حالية
- Outlook الشخصي يحتاج OAuth (قيد التطوير).
- Gmail يشتغل بكلمة مرور التطبيقات (تحتاج تفعيل التحقق بخطوتين).
- حساب «سومر السيادي» يحتاج خادم بريد خاص (المرحلة الجاية).
